## Contributing to Navara

Thank you for your interest in contributing to Navara. Contributions of every kind are welcome: bug reports, feature proposals, code, documentation and translations.

The full contribution guide, including the development setup, coding conventions and the pull request process, is maintained in the repository. Please read it before opening an Issue or a Pull Request.

**Contribution guide**: [https://github.com/maplibre/navara/blob/main/CONTRIBUTING.md](https://github.com/maplibre/navara/blob/main/CONTRIBUTING.md)

Issues and Pull Requests are managed in the same repository: [https://github.com/maplibre/navara](https://github.com/maplibre/navara). Improvements to this documentation site, from fixing typos to adding translations and examples, follow the same process.
