## 既知の制限

- `tiles` 配列の最初の URL のみが使用されます（負荷分散は未サポート）
- テキストハロー（`text-halo-color`、`text-halo-width`）はレイヤー構築時に一度評価され、フィーチャーごとの評価ではありません
- 大量のシンボルレイヤーはローエンドデバイスでパフォーマンスに影響する可能性があります
