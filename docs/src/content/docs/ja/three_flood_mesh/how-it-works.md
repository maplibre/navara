洪水の時系列は、緯度経度の等間隔格子上の水面の高さの時系列です。`loadTimeSeriesFlood` はこれを Zarr グループから読み、水が一度でも届くノード（一度でも浸水するセルとその隣のセル）だけを保持します。すべてのフレームを一度に GPU へ送るので、[TimeSeriesFloodMeshDesc](../api/time-series-flood-mesh-desc/) の `frame` を変えても再読み込みや再構築は行われません。2 つのフレームの間では、両方の高さを混ぜ、汀線を各フレームの汀線までの距離に沿って動かします（[frame](../api/time-series-flood-mesh-desc/#frame) を参照）。

## データ形式

`loadTimeSeriesFlood` は、以下の配列を持つ Zarr グループ（Zarr v2 または v3）を読み込みます。配列名は既定値で、`variables` で変更できます。

| 配列          | 形                 | 内容                                                                                                                                                                     |
| ------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `water_level` | `[time, lat, lon]` | WGS84 楕円体からの水面の高さ（メートル）。値が NaN または配列の fill value のセルは乾いているものとして扱います。CF の `scale_factor` と `add_offset` 属性を適用します。 |
| `time`        | `[time]`           | 各フレームの時刻。`units` 属性は CF に従います（例：`"seconds since 1970-01-01T00:00:00Z"`）。タイムゾーンのない基準時刻は UTC として読みます。                          |
| `lat`         | `[lat]`            | セル中心の緯度（度）。等間隔で、昇順・降順のどちらでも構いません。                                                                                                       |
| `lon`         | `[lon]`            | セル中心の経度（度）。等間隔で、昇順・降順のどちらでも構いません。                                                                                                       |

水を含まないチャンクはストアから省略できます。存在しないチャンクは乾いているものとして読みます。圧縮方式は gzip、zlib、zstd、Blosc、LZ4 に対応しています。コンバーターは zstd で書き出します。zstd のデコーダー（gzip 圧縮で約 250 KB）は、それを必要とする最初のチャンクを読むときに読み込まれます。

フレームの時間間隔は一定でなくて構いません。2 つのフレームの間では、汀線は各フレームの汀線までの符号付き距離に沿って移動します。距離の配列がない場合、`loadTimeSeriesFlood` は読み込み中にこれを計算し、数十万セルの規模では数秒かかります（[Worker での読み込み](../usage-examples/#worker-での読み込み) を参照）。これを避けるには、符号付き距離（メートル、浸水している側が負）の `[time, lat, lon]` 配列を保存し、その名前をグループの `signed_distance` 属性か `variables.signedDistance` に指定してください。

### プロパティ

水面は、シミュレーションが出力する流速や浸水深のような、セルの数値プロパティで色分けできます（`colorBy` を参照）。各プロパティはグループの配列として一つずつ持ち、形は `[time, lat, lon]`、時間で値が変わらないものは `[lat, lon]` です。CF の `scale_factor` と `add_offset` を適用し、fill value は欠損として扱います。グループの `properties` 属性に名前を列挙します。`variables.properties` を指定した場合はそちらを使います。プロパティの CF の `units` と `long_name` 属性は、`series.properties` の `units` と `label` になり、凡例に使えます。

プロパティは、変換時に指定した精度（[変換関数](../api/converters/#共通のオプション) を参照）で値域が収まる最小の整数型（1 バイト、16 ビット整数）にパックされ、精度を指定しなければ float32 で保存されます。配列に `actual_range` と `robust_range` 属性があれば、値域と 2 / 98 パーセンタイルをそこから `series.properties` に取り、読み込み時に計測しません。

グループの `ground` 属性（または `variables.ground`）が示す地盤高は、`depth` を求めるために読み込みますが、`variables.properties` に含めない限りそれ自体はプロパティになりません。保存されたプロパティに加えて、`loadTimeSeriesFlood` は以下を派生させます（同名のプロパティがストアにある場合はそちらを使います）。

| プロパティ | 形                 | 内容                                                                                                                                                                             |
| ---------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `depth`    | `[time, lat, lon]` | 浸水深（メートル）。水位と、WGS84 楕円体からの地盤高から求めます                                                                                                                 |
| `speed`    | `[time, lat, lon]` | [流れ](#流れ)から求めた流速の大きさ（m/s）                                                                                                                                       |
| `arrival`  | `[lat, lon]`       | 最初のフレームからセルが最初に浸水するまでの時間（時間単位）                                                                                                                     |
| `duration` | `[lat, lon]`       | 時系列全体でセルが浸水している時間（時間単位）                                                                                                                                   |
| `rate`     | `[time, lat, lon]` | 次のフレームまでの水位の変化率（メートル毎時）。描画される水位はその区間を通してこの率で変わるので、区間内では補間せず同じ値を表示します。最後のフレームは直前の値を繰り返します |

### 流れ

波をシミュレーションの流れに乗せて動かせます。流速を東向き・北向きの 2 つの配列（m/s）として持ちます。形は `[time, lat, lon]`、時間で変わらないものは `[lat, lon]` です。グループの `flow` 属性に `[east, north]` の順で名前を指定するか、`variables.flow` で指定します。変換関数は `flow_east` と `flow_north` という名前のプロパティをこの配列として扱います。モデルの軸は異なることがあります。北から回転しているものは回転し、`y` が南向きのように逆向きの成分は符号を反転してください。

`loadTimeSeriesFlood` は流速を、浸水していて両方の成分が揃うセルでのみ読み取り、汀線の外へ延長します。`variables.properties` に含めない限り、これらの配列自体はプロパティになりません。`extent: "max"` では、各ノードの最も速い流れを使います。

波は、波自身の動きに加えて、フレームの再生速度によらず実際の速さで、描画が続く間だけ流れます。波はカメラから約 2 km までに消えていくので、それより遠くでは流れも見えません。流れのある時系列は、ピクセルあたり 2 倍の波のテクセルをサンプルします。

`speed` だけを持つ場合のように両方の成分が揃わない時系列には、流れはありません。`waveDirection`、`waveStrength`、`flowSpeed` で水面全体の波を設定します。

### GPU メモリ

すべてのフレームを一度にアップロードします。ノード（一度でも浸水するセルとその隣のセル）が `N` 個、フレームが `F` 個の時系列は、1 レイヤーあたり `R = 2048 × ⌈N / 2048⌉` テクセルで、次のテクスチャを使います。

- **水面**：常に `R × (F + 1) × 4` バイト。
- **流れ**：流れのある時系列では常に `R × (F + 1) × 4` バイト。
- **表示中のプロパティ**：時間で変わるものは `R × (F + 1) × 2` バイト、変わらないものは `R × 2` バイト。直近に表示した 3 つまでは再利用のため保持します。

テクスチャの大きさは GPU で制限されます。行数 `⌈N / 2048⌉` と、水の周りの `W × H` セルを覆うノード参照テクスチャの行数 `⌈W × H / 2048⌉` は `MAX_TEXTURE_SIZE` 以下、レイヤー数 `F + 1` は `MAX_ARRAY_TEXTURE_LAYERS` 以下である必要があります。WebGL 2 で保証される最小値は 2048 と 256 です。超える時系列は読み込みがエラーになります。

例えば 20 万ノード・100 フレームなら、水面に約 81 MB、`depth` の表示中にさらに 40 MB を使います。変換関数は書き出したグループについてこのサイズ（`textureBytes`）を返します。対象とする端末に収まるよう、フレームを間引いてください（`interval`、`tolerance`）。
