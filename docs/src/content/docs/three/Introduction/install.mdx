## Installing the Packages

Navara packages are published on npm under the [`@navaramap`](https://www.npmjs.com/org/navaramap) scope. Install `@navaramap/three` together with its peer dependencies `three` and `postprocessing`. Most apps also want `@navaramap/three-default-plugin`, which registers the built-in mesh, effect, and light Descriptors:

<Tabs syncKey="pkg">

<TabItem label="npm">

```bash
npm install @navaramap/three @navaramap/three-default-plugin three postprocessing
```

</TabItem>

<TabItem label="yarn">

```bash
yarn add @navaramap/three @navaramap/three-default-plugin three postprocessing
```

</TabItem>

<TabItem label="pnpm">

```bash
pnpm add @navaramap/three @navaramap/three-default-plugin three postprocessing
```

</TabItem>

</Tabs>

## Nightly Builds

Features marked **Nightly** in this documentation and in the examples are not in the latest release yet. They ship in nightly builds, which are published from the `main` branch under the npm `nightly` dist-tag. Install every Navara package from that tag, because the packages of one build depend on each other at exact versions:

<Tabs syncKey="pkg">

<TabItem label="npm">

```bash
npm install @navaramap/three@nightly @navaramap/three-default-plugin@nightly three postprocessing
```

</TabItem>

<TabItem label="yarn">

```bash
yarn add @navaramap/three@nightly @navaramap/three-default-plugin@nightly three postprocessing
```

</TabItem>

<TabItem label="pnpm">

```bash
pnpm add @navaramap/three@nightly @navaramap/three-default-plugin@nightly three postprocessing
```

</TabItem>

</Tabs>

A nightly version such as `0.3.2-nightly.13.g303ac6f` sorts after the latest release and before the next one. Nightly builds have no changelog, and their API can change before the release. See [Release Cycle](../../../guides/community/release-cycle/) for how often each channel is published and what it guarantees.

Some packages, such as [`@navaramap/three-flood-mesh`](../../../three_flood_mesh/about/), are published only in nightly builds until they join a release. Install them from the same tag as the other Navara packages.
