# Water and weather

## Water

- **Waves are set per layer, with `waveStrength` and `waveDirection`.** On `polygon`/`model` materials with `water: true`, and on `terrain` for the quantized-mesh watermask's sea, which shades as full water with no layer (`terrain` also takes `waveExaggeration`). `waveStrength` (default 5) sets the size, steepness and speed of the waves: about 1 is a calm ripple, 5 moderate, 20 a storm. It is not a current's speed: `flowSpeed` (m/s, default 0) is, carrying the waves along `waveDirection` without changing their size or slope. `waveDirection` (default 0) is where the waves travel, in degrees clockwise from north. `waveExaggeration` scales only the slopes, keeping size and speed (`0` = still mirror; `waveStrength: 0` still has fine ripples). `waterScale` caps the wave size (`"ocean"` default, `"large"` bay/large lake, `"medium"` lake/wide river, `"small"` river/pond), so set it on inland water or rivers show ocean swell. The watermask sea takes its body color from the imagery under it (often a flat bright blue offshore) unless the terrain layer sets `terrain: { waterMaskColor }`; `layer.update({ terrain: { waterMaskColor: undefined } })` uses the imagery color again (omitting the key keeps the current color). Water ignores `reflectivity`, `roughness`, `shininess`, `specular`, `specularStrength` and `ior`. All waves keep their size in meters and turn into uniform roughness (wider sun glitter) from about 2 km away, and they only move while frames render (view constructor option `animation: true`, or `view.animation = true`).
- **Water reflects the sky env map only when a `sky: { envMap: true }` mesh exists, otherwise the light probe's low-frequency sky.** `addDefaultPhotorealScene()` adds no env-map sky, so add a second `view.addMesh({ sky: { envMap: true } })` for the bright horizon in grazing views. That mesh renders only into the env cube, so the regular sky stays. Worked page: `example/pages/water-reflection`.
- **Blending dilutes polygon water.** `transparent` + `opacity` scale the reflection along with the body color, so keep water polygons opaque, or close to it, when the reflection matters (`example/pages/use-cases/photorealistic` settles on `opacity: 0.85`).

Related: turning the sea on (`requestWaterMask: true` on the `quantized-mesh` source) and making it reflective with SSR → [recipes.md](recipes.md); `aerialPerspective.specular` on water → [lighting.md](lighting.md).

## Snow and rain

- **`SnowMeshDesc` / `RainMeshDesc` `maxHeight` is an opacity fade, not a spawn ceiling.** Every frame the material opacity is multiplied by `max(1 - cameraHeight / maxHeight, 0)`, so with the default `maxHeight: 3000` a camera at or above 3 km renders _zero_ visible snow while everything still runs — a silent empty screenshot. Particles also spawn in an `areaWidth` x `areaHeight` box around the camera and `size` is world-space (`sizeAttenuation`), so flakes only read at their nominal size when the camera is inside the weather, not looking at it from above.
